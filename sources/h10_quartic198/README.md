# A quartic in 198 variables

This package records the 14 November 2026 research attack on Jose Brox's 206-variable quartic. The repository had already advanced to 204 variables at the pinned commit. The final result here has 198 total variables (197 existential variables plus the input), degree exactly 4, 184 quadratic residuals, integer content 1, and exactly 2,945 monomials.

This is a six-variable improvement over that 204 baseline. It is not the substantial reduction originally sought. The proof retains the baseline arithmetic premises, introduces no additional abc hypothesis, and leaves the sufficient defining parameter ineffective. The inherited arithmetic foundations have not received a complete independent audit here.

## Main files

- `h10-quartic198.pdf`: proof, coefficient bounds, and larger unsuccessful routes.
- `arithmetic/inverse_vieta_198.tex`: editable proof source.
- `circuits/inverse198/balanced-quadratic.json`: all 184 primitive quadratic residuals.
- `circuits/inverse198/balanced-polynomial.json`: the complete expanded quartic.
- `circuits/inverse198/README.md`: coordinate conventions and exact transformations.
- `audit/`: additional independent reconstruction and arithmetic review.

For the preferred balanced polynomial, set C=149^N. A term record with parameterPower=a, monomial=[i1,...,ik], and coefficient=c means c*C^a*Y_i1*...*Y_ik. Repeated indices denote powers. Coordinate 1 is the rational input X; C is a fixed coefficient parameter and is not counted as an existential variable. Collect records sharing a coordinate monomial after substituting C. There are 2,959 parameter-separated records and 2,945 nonzero coordinate monomials for every N>=1.

The exact coefficient height is max(H0,31581660^28*149^(2N)), where H0=(5898050446009651968*31581660^28)^2. The second term dominates for N>=57. This is only a coefficient crossover; no numerical N is certified to define Z. The unbalanced presentation has height max(H0,149^(4N+2)).

## Reproduction

Python 3 and SymPy suffice for deterministic construction and independent verification. Run `python verify.py` from this directory. It rebuilds the 200-variable intermediate and the 198-variable unbalanced and balanced tables, then runs independent checks and the exact obstruction certificates. The optimization searches are retained separately; some require SciPy, but none is needed to reconstruct the final result from its saved integer certificates.

The finite checks certify algebraic identities, counts, rescalings, and coefficients. They do not prove the inherited arithmetic premises. The written proof separately handles soundness, completeness, zero denominators, tangent cases, and quantifier order.

## Research status

The `alternatives/`, `poles/`, and structural notes record unsuccessful larger attacks. Earlier scalar chart variants in those notes are exploratory and superseded by `charts/inverse_vieta.md`. A monic Pell relation could eliminate the entire input point if its nonzero residual could be excluded, but the available height inequalities leave a substantive gap. These possibilities are not claimed as further variable records.
