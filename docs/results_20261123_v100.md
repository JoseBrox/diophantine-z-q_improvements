## The invariant that fixes the order of choices

The earlier adaptive-spacing candidate depended on a secant coordinate
that changed when the reference index was retuned after prime selection.
Its completeness argument remains blocked. The present theorem uses
an aggregate of **fixed difference points**, so the same problem does
not occur.

Write `a_s` for the common scalar label and `K=v2(a_s)>=2`. The
retained Lucas recurrence and formal-group calculation give

```math
v_2(U_{a_s})=2K+1,\qquad v_2(b_s-1)=K,
\qquad v_2\bigl(x([n]R_0)\bigr)=-2v_2(n)-1
```

for the relevant even indices. In each aggregate, the common point
`[U_(a_s)]R0` has a strictly smaller 2-adic valuation than every other
contribution. The retained aggregate shift therefore satisfies

```math
v_2(T_i)=-4K-4
```

for every input. All contact positions have valuation at least this
same lower bound, in both the general and specified charts.

Choose the root input block b and set `D=T_b/16`. If two distinct block
indices lie between 0 and 15, their difference has 2-adic valuation at
most 3. Therefore

```math
v_2((i-j)D)\le-4K-5.
```

It cannot equal a difference of old contact positions. Thus these
fixed translations separate every contact list, including repeated
integer inputs. The current thirteen- and eleven-block systems both
fit within the sixteen-index range.

The difference points and their aggregate are fixed before the contact
primes are chosen. They stay fixed while the reference is subsequently
adjusted. The existing finite-family supplier, avoidance conditions,
local limits and real approximation therefore apply with unchanged
hypotheses. The common contact center remains free.

## The exact affine coordinate saving

In the general chart, the two retained root-block contact coordinates
are `t=lambda/rho` and `t_prime=(lambda+T_b)/rho`; the spacing coordinate
is `d=D/rho`. In the specified chart the same coordinates are unscaled.
Both charts therefore have the same affine substitution:

```math
d=(t_{\rm prime}-t)/16.
```

Substitute this expression everywhere and delete d. There is no new
equation, variable denominator or guard. Quadratic degree is preserved.
Soundness follows by restoring the old d by this formula; completeness
uses the fixed-spacing construction above. The ordinary-abc route
already has fixed offsets and is unchanged.
