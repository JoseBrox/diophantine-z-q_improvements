# v87: an explicit 163-variable Busy Beaver index below 2^826

**New sharpened bound.** Under the arithmetic, elliptic weighted-graph
height and finite-state compiler lemmas inherited from the user-supplied
Version 22 and the [v86 proof](../papers/quartic/bb163_fixed_20261120_v86.tex),
one *fixed* degree-four 163-variable polynomial defines
\(\mathbb Z\) over \(\mathbb Q\). Unlike the old ineffective-family
argument, its Busy Beaver argument is an explicit natural number:

\[
\begin{aligned}
\psi&=\prod_{j=2}^{90}(3j+1),\\
\kappa&=27160+16032\psi,\\
\boxed{t_1}&=2^{20}(16\kappa+2^{186}+1)(2^{186}+3).
\end{aligned}
\]

The exact base-10 value of \(t_1\) is

It has 249 decimal digits and satisfies \(2^{825}<t_1<2^{826}\).
The polynomial is the original v82 163-variable quartic with
\(C=149^{\mathrm{BB}(t_1)}\). No new variable or equation is added.

Its exact coefficient height is
\[
H(F_{\mathrm{BB}(t_1)})=149^{4\mathrm{BB}(t_1)+2}
                         <\mathrm{BB}(2^{1010}).
\]
The three nonconstant coefficient profiles remain
\(-6615898C^2\), \(-298C^2\), and \(22201C^4\); the remaining
2,786 monomial coefficients are fixed in the
[original table](../computation/variable_reductions_v82/general/quartic163/polynomial.json).
This is a fully specified polynomial **relative to Busy Beaver**,
not an evaluated decimal-coefficient polynomial. A simple sufficient
rounded argument is \(t=2^{826}\), but \(t_1\) is smaller.

## Why the index is smaller

The supplied v22 proof showed \(t=2^{1500}\).
The [v86 continuation](results_20261120_v86.md) evaluated the
exact worst-stratum constants \(\Lambda,\psi\) in von Buhren's
quantitative Theorem 3.1, using
\[
\dim V=9,\quad m=10,\quad N_A+1=6561,\quad N_P+1=4,\quad
\deg V\le 10!3^8.
\]
It obtained \(\operatorname{bitlength}(\Lambda)=2004\) and
\(\operatorname{bitlength}(\psi)=602\), replacing
\(U=2^{2^{1000}}\) by \(2^{2^{616}}\).

The extra improvement here is to **avoid rounding the exponent**.
The explicit bounds from Theorem 3.1 give
\[
\log_2e_3<27150+16032\psi=\kappa-10,\quad
\log_2(e_2^2)<2+8016\psi,\quad
\log_2\mu<2+2004\psi,
\]
and the logarithm of the total number of records is less than
\(36+8016\psi<\kappa\). Thus \(U=2^\kappa\)
still suffices, but
\[
\kappa /2^{616}\approx0.9614812203669667,
\]
and only \(\kappa\), rather than \(2^{616}\), binary digits are
needed to hardwire the unknown final record ordinal.

The v22 counter compiler has a fixed core of fewer than \(2^{186}\)
instructions and counters and a reusable loader costing fewer than
16 instructions per ordinal bit. Hardcoding \(\kappa\) itself costs
only 616 bits, within the existing fixed-core budget. Its total
binary state count is strictly smaller than
\[
2^{20}(16\kappa+2^{186}+1)(2^{186}+3)=t_1.
\]
The program for the final record halts after more than
\(U^3(R_{\mathrm{final}}+3)\) steps. The unchanged v86 arithmetic
argument proves that this is a sufficient defining threshold.
Consequently \(N=\mathrm{BB}(t_1)\) exceeds that threshold.

Because \(t_1<2^{826}\), the independent coefficient wrapper
has fewer than \(2^{837}\) hardwired table bits, fewer than
\(2^{841}\) instructions and fewer than \(2^{149}\) counters.
The same compiler then uses fewer than \(2^{1010}\)
binary working states, proving the strict coefficient-height
bound above.

## Files and review scope

The mathematical proof is
[bb163_compact_record_20261120_v87.tex](../papers/quartic/bb163_compact_record_20261120_v87.tex).
The [exact checker](../scripts/verify_v87.py) and
[machine-readable parameter certificate](../computation/bb_v87/certificate.json)
recompute the integers, degree bounds, state margins and
coefficient wrapper. The previous v86 polynomial manuscript and
the original 163-variable coefficient tables are unchanged.

As with the v22 and v86 result, validity depends on the retained
arithmetic, weighted-geometry and compiler lemmas. The finite checker
does not independently prove those lemmas, nor does it evaluate
the Busy Beaver function. The TeX proof makes these dependencies
explicit and does not silently treat them as computational results.
