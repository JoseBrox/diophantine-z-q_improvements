# A fixed Busy Beaver index for the 163-variable quartic (v86)

**New result, conditional on the inherited arithmetic/geometry/compiler
arguments in the supplied v22 manuscript.** The pinned v22 source
`quartic_v22.tex` (commit `4b43ba288b9b8639cc5cc85f8c1507d64c698659`,
SHA-256 `3ac000a6481badf818d58fb409d3b217b22709c7cb92039935fb5e68e6d452b6`)
proved a 163-variable quartic at `N=BB(2^1500)`, with height
`<BB(2^2000)`. This continuation derives the sharper numerical choice

```text
t0 = 2^20 * (2^620 + 2^186 + 1) * (2^186 + 3)
N  = BB(t0)
C  = 149^N
```

Here `2^826 < t0 < 2^827` and `t0` is an ordinary, fully
specified integer; no Busy Beaver oracle is needed to select it.
The original 163-variable quadratic table with this fixed coefficient
specialization defines the integers, **provided the mathematical
interfaces used in v22 hold**. It has exact height

```text
149^(4*BB(t0)+2) < BB(2^1012).
```

The [five-page TeX proof](../papers/quartic/bb163_fixed_20261120_v86.tex)
details the transfer. The coefficients are exactly those of the
[163-variable coefficient table](../computation/variable_reductions_v82/general/quartic163/polynomial.json);
only three profiles depend on `C`, namely `-6615898*C^2`,
`-298*C^2`, `22201*C^4`, on distinct monomials.
The 163-variable family proof and all previous data are preserved
unchanged.

## What was improved

The original weighted-trace graph has at most 256 torsion strata.
At the worst stratum its dimension is nine and von Buhren's
Theorem 3.1 uses `m=10`, `N_A+1=3^8`, `N_P+1=4`,
`deg V <= 10!*3^8`. Evaluating its exact constants gives
`bitlength(Lambda)=2004` and `bitlength(psi)=602`.
The resulting Vojta constants and total record count all fit under

```text
U = 2^(2^616),
```

instead of v22's `2^(2^1000)`. More explicitly,

```text
log2(e1)   < 3 + 2004*psi
log2(e2^2) < 2 + 8016*psi
log2(mu)   < 2 + 2004*psi
log2(e3)   < 27150 + 16032*psi
log2(records) < 36 + 8016*psi < 2^616.
```

Each v22 record is defined by exact arithmetic in
`Q(sqrt(2))`; Theorem 3.1 forces a total of fewer than `U`
records without detecting the final one.

Writing `Rfinal` for the last record value, the retained
weighted-height estimate is valid with
`A=U^2`, `J=U^2*(Rfinal+3)`.
The arithmetic argument improves the sufficient parameter
threshold from `U^1000*(Rfinal+3)` to

```text
G(Rfinal) = U^3*(Rfinal+3).
```

The crucial scalar-height error is at most
`45*U^3*N*149^(-2*N) <1/4` after dividing by the square
of the maximum source index. The cubic-divisibility comparison
has exponent `35/18 < 2`, and the remaining input error is
eliminated by the same Lucas bound. Integer completeness holds
already for every `N>=1` by the unchanged v22 ordered witnesses.

The v22 record-selector program has **1,506 AST nodes, 16
functions and acyclic call depth 10**; this was parsed
independently from the user-supplied source, without executing
its Python text. Hardwiring an ordinal below `U` requires at
most `2^616` bits. Combining the two-scratch loader and the
fixed `2^186`-instruction/counter core yields

```text
instructions L < 2^620 + 2^186
counters     R < 2^186 + 2
binary working states < 2^20*(L+1)*(R+1) < t0.
```

For the actual final-record ordinal that program halts after
more than `G(Rfinal)` steps, so `G(Rfinal)<BB(t0)`.
The separate hardwired maximizing-table interpreter uses fewer
than `2^1012` binary states, giving the strict height bound.

## Verification and limitations

The published [exact-integer checker](../scripts/verify_v86.py)
regenerates the `Lambda,psi` envelopes, machine-state budgets,
and selected arithmetic inequalities. When the original uploaded
file is accessible to the reproducing agent, run

```sh
python -B scripts/verify_v86.py \
  --source-tex /path/to/quartic_v22.tex \
  --report /tmp/v86.json
```

to authenticate the source bytes and its embedded selector AST.

**Scope:** the mathematical proof uses the complete inherited v22
geometric graph-height estimate, no-exceptional-translate proof,
arithmetic contact and completeness theorems, and the explicit
counter-to-binary compiler. The current independent numerical
verification does not itself reprove all those foundations; these
dependencies are identified rather than silently assumed verified.
The earlier v85 statement that no **numerical** BB index had yet
been proved was accurate before the v22 proof was supplied; it
is superseded by the v22 argument and this refinement, subject
to these inherited proof dependencies.

The simple rounded value `t=2^827` is also sufficient. The
unrounded `t0` is smaller and is the current bound recorded here.
