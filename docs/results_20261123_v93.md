## 1. Correct the source before interpreting undecidability

The earlier tables used an emended version of Jones's expanded 1980
Theorem 3, with its precise universality left as `U_em`. The new
[source proof](../undecidability/source_repair_v93/corrected_jones_source.tex)
([PDF](../undecidability/source_repair_v93/corrected_jones_source.pdf)) starts
instead from Jones's preceding **Theorem 2**, the coding theorem with one
central-binomial condition and a power-of-two condition.

The independently proved binomial certificate supplies the correct polynomial
replacement. With `M=n^2`, its parameter is

```math
p=2ws^2r^2n^6,
\qquad a=(wn^2+1)rsn^2.
```

Only two quadratic rows change: the reused `sr` register becomes `rY`,
where `Y=sn^2`, and `a=(U+1)sr`, where `U=wn^2`. No coordinate or row is
added. The proof checks the signed-Pell reconstruction, reciprocal guard,
positive witnesses, and the cofinite instance restriction.

This gives a new corrected source reduced to the cited classical theorem;
it does not prove that the old `n^2` source was correct. The old tables and
`U_em` qualification remain historical records. Jones's coding theorem is
an explicit external input, not an independently reproduced coding proof.
The note states the theorem without proof, and the original note's public
transcription was checked; the manuscript documents this sourcing scope.
Every retained integrality premise remains separately qualified.

The [complete corrected tables](../undecidability/source_repair_v93/coefficients)
include the original v92, ceiling-power, and final abc-contact variants.
Their metadata separates the current source from the historical source;
all two-row changes and all unchanged residuals are checked independently.

## 2. Compute the fixed power with 29 fewer coordinates

The [power theorem](../undecidability/papers/ceiling_power_quartic_checkpoint.tex)
([PDF](../undecidability/papers/ceiling_power_quartic_checkpoint.pdf)) starts
with the existing input square and the two coordinates for `b^3` and `b^5`.
For `M=5^60`, set

```math
e_j=\left\lceil M/2^{137-j}\right\rceil,\qquad 0\le j\le137.
```

Each step has `e_j=2e_(j-1)` or `e_j=2e_(j-1)-1`. The quadratic equations
`v_next=v^2` and `b*v_next=v^2` therefore compute each step in one coordinate.
The unchanged prefix and positivity equations already force `b>0`; the
proof does not infer nonvanishing circularly from the new circuit.

The complete power circuit uses **139** coordinates instead of **168**.
This saves 29 variables and rows in all three systems. Both reconstruction
maps are given, and the occurrence audit confirms that no removed intermediate
is used elsewhere. The 139-coordinate lower bound is restricted to the stated
triangular monomial chart with nonnegative exponents; it does not constrain
arbitrary Diophantine systems or a different universal source.

## 3. Share the abc contact parameter and its square

The [fixed-grid theorem](../undecidability/papers/abc_fixed_contact_offsets_v93.tex)
([PDF](../undecidability/papers/abc_fixed_contact_offsets_v93.pdf)) uses the
proved two-adic integrality of every contact position for integer witnesses.
For k families, fixed translations

```math
\delta_i=\frac{i}{2^{\lceil\log_2 k\rceil}},\qquad 0\le i<k,
```

lie in distinct cosets modulo the two-adic integers. Thus every pair of
translated contact lists is disjoint, uniformly in the integer inputs.
No bound on the real size of the input-dependent centers is needed.
For twelve inputs a common denominator of 16 suffices.

Writing all contact parameters as `z_i=z+delta_i` removes eleven coordinates.
The relation `S_i-T_i=2z_i^2` then permits one common square `q=z^2`:

```math
S_i=T_i+2q+4\delta_i z+2\delta_i^2.
```

These substitutions are affine in the stored coordinates. They remove twelve
sum coordinates at the cost of one common square, saving eleven more.
The net saving is **22 variables and 11 equations**. No row exceeds degree
two; multiplying rows by nonzero integer denominators preserves their zeros.

Soundness follows by recovering each original block. Completeness uses the
retained finite-family prime supplier and the previously proved reference
preparation; fixed translation denominators are included explicitly in finite
avoidance. At fixed places and infinity, `z_i/z` tends to one, preserving the
old limits. The sufficient source threshold is unchanged. For k nonzero
integer inputs the tuple certificate uses **48k+8 coordinates and 41k+5 rows**,
including the inputs. Positive corrected-source witnesses satisfy its domain.

## 4. A smaller-degree guarded finite-algebra encoder

The [paired spectral theorem](../undecidability/papers/paired_spectral_encoder.tex)
([PDF](../undecidability/papers/paired_spectral_encoder.pdf)) encodes a rational
character of a finite algebra whose chosen guard is nonzero. It handles
nilpotents, repeated roots, an empty permitted locus, and source denominators
that vanish at excluded characters.

For algebra rank n, ell guarded generators, and multiplication-entry degree d,
put `J=ell*n*(n+1)/2`. The construction removes the mandatory diagonal zero
factors from the tensor-difference characteristic polynomials and pairs each
difference with its negative. Their squared differences form a degree-J
polynomial. A spectral envelope using only the original matrix entries is
kept separate from the characteristic-coefficient bounds.

The resulting integer-polynomial recipe has one extra rational coordinate
and degree at most

```math
2n(J+1)\bigl[1+d\{1+(4+6\ell)J\}\bigr].
```

For fixed generator count, the rank growth improves from order `n^7*d` to
order `n^5*d`. Complete multiplication-matrix and coefficient-stratum formulas
are supplied, so this is a specified polynomial construction rather than only
a degree estimate. The large matrices are not expanded.
