## Nonlinear shared Pell certificate

[v153](../undecidability/bilinear_pell_obstruction_v153/README.md) proves that any fixed bilinear merger \(\lambda hj+\mu h+\nu j+\xi\), \(\lambda\ne0\), admits the same kind of global false-source witnesses as the previously disproved affine merger. Both quotients can even be positive. This is a negative result for that class, not a lower bound for all possible presentations.

The sound two-moment repair \(h+j,\ hj\in\mathbb Z\) follows by monic rational-root integrality and preserves canonical completeness, but still costs two integer predicates.

[v154](../undecidability/high_genus_pell_v154/README.md) gives one genuinely nonlinear certified integer \(\Lambda=h^{2m}+j^{2m}\) with an explicit size guard. The fixed-fiber curve has genus \(8m^2-4m+1\), so Faltings' theorem rules out the old dense infinite deformation. Canonical completeness is proved using the unbounded third-Pell progression. Joint integrality is **not** proved: local nonintegral branches remain, and an explicit rational point on a guarded genus-five fiber disproves the proposed implication for arbitrary abstract Pell data. The specialized packed-source fibers are not settled by that example. The candidate is not installed in any preferred compiler.
