## Mathematical changes

For each nonzero factor, the norm is taken in a Galois-stable subalgebra
containing its square-exponent support. This removes repeated norm powers
without changing their nonzero locus. Integrality is proved by Galois descent
and integrality over the integer polynomial ring. The final separating element
uses the entire quadratic tower and individual polynomial root envelopes. Its
proof includes nonreal roots, arbitrarily small nonzero radicands, dependent
square classes and excluded nonreduced boundary fibers.

The proof and finite integer-polynomial recipe are in
`papers/finite_algebra/subalgebra_norms_20261114_v30.tex` and
`computation/few_variables/subalgebra_norms_v30`. The independent checker does
not import the producer's binary-subspace or bound routines. Twenty mutations,
nine exact rank-eight examples, and eight additional coefficient-parameter
fixtures supplement the universal proofs. The production determinants are not
expanded, and computational checks do not establish the inherited infinite
arithmetic premises.

## Common pole parameters

`papers/pole_parameters/common_twists_20261114_v30.tex` applies the supplied
finite-family twist theorem, credited separately from Jaswal's Hexagon two-twist
Theorem 1.2. A common nontrivial input square class with k distinct nontrivial
complement classes needs k+1 retained pole parameters on the stated realization
locus. Pairwise-coprime admissible complements suffice. A change of base square
class extends the conclusion to some overlapping families; an exact example
has complements 89*137 and 89*257, translated to 89, 137 and 257.

The uniform polynomial encoding uses existing input and complement values as
representatives, not new variables for their squarefree parts. All square-root
choices remain enforced. The current global completeness construction does not
supply the required common input square class. The theorem therefore does not
establish a 12-variable or 24-variable definition.

The local interpreter is Python 3.13.5, not native Python 3.12. The unmodified
legacy suite first stops at a pinned Python AST representation. The optional
`scripts/python313_legacy_compat.py` restores the Python 3.12 empty-field AST
serialization and its mtime-zero zlib gzip header. Neither source files,
mathematical arithmetic nor verification assertions are changed. The helper
checks the original byte fingerprints; native Python 3.12 remains the release
CI target. The integration receipt distinguishes the unmodified attempt from
the compatibility run and records their actual outcomes.
