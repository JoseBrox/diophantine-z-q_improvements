## Computation and independence

checker does not import the producer. All 73 / 186 current equations and all
941 / 2908 coefficient profiles are checked, with all 188 predecessor rows
also reconstructed. Algebraic domain identities are verified symbolically.

independent non-author review, formal Lean verification or protected-controller
acceptance. The foundational audits and complete legacy verification run remain
separate obligations. No complete numerical witness tuple is claimed.
