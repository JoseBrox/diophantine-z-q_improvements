# Elliptic height and local-precision audit, 13 November 2026

This research branch adds two proved auxiliary developments and a scoped audit of Sun's arXiv:2611.14605v1 and upstream PR30 at c84bbfa4dbe8f32fd3bf29df029f7b7849d36202. It does not change the current main-branch polynomial records or claim complete acceptance of the imported arithmetic foundations.

- [Product-height paper](../../papers/elliptic_heights/product_height_20261113_v23.tex): equality holds exactly when the nonzero indices have the same 2-adic valuation. Includes positive weights, a number-field criterion, three-scale bounds, and the exact log(41) counterexample for indices 1 and 2.

- [Exact checker](../../computation/sun_pr30_audit/check.py) and [25-stage certificate](../../data/audits/sun_pr30_20261113.json).
