The complete general quartic checkpoint now has **1103 rational variables
and 953 quadratic equations**. The specified-interface checkpoint has
**1283 variables and 1109 equations**. The ordinary-abc checkpoint remains

The new changes are exact equivalences of complete systems. The old

## Three reusable quadratic reductions

The [scalar rechart](../undecidability/papers/scalar_rechart_quartic_checkpoint.tex)
([PDF](../undecidability/papers/scalar_rechart_quartic_checkpoint.pdf)) starts
from the common point equations `R_i L_i=Z^2` and `UV=L_i P_i`.
They imply `P_i/R_i=UV/Z^2`, so those quotients are already identical
on every solution. One common scalar abscissa replaces the private
products. The proof establishes the necessary nonvanishing from retained
equations and covers tangent and zero-component cases. In the specified
interface, reversing an old homogeneous pole scaling then removes twelve
inverse-normalizer variables. The savings are **42 / 32 variables**.

The [norm-polynomial theorem](../undecidability/papers/scalar_norm_compression.tex)
([PDF](../undecidability/papers/scalar_norm_compression.pdf)) applies to

```math
R_i(J_i-Q)=K,\qquad \tau_i\operatorname{Tr}(J_i-Q)=N(J_i).
```

For common `K,Q`, put `T=Tr(K)` and introduce three common rational
coordinates with

```math
AT=N(K),\qquad BT=\operatorname{Tr}(K\overline Q),\qquad CT=N(Q).
```

The private field `J_i` disappears, replaced by the single equation

```math
R_i\tau_i=A+BR_i+CR_i^2.
```

The squared normalizers are already stored. The proof shows `T` is
automatically nonzero on both systems, so no inverse register is omitted.
For twelve blocks the saving is **21 variables and 21 equations**.
The paper also states the corresponding principle for higher-degree
number fields, with the additional coefficient costs explicitly noted.

The [detector-trace theorem](../undecidability/papers/detector_trace_compression.tex)
([PDF](../undecidability/papers/detector_trace_compression.pdf)) applies to

```math
a_iB=uW_i,\qquad
(D_i+h)\operatorname{Tr}(W_i)=N(W_i)+h^2,
```

where `B,u,h` are common and `u,h` are already nonzero. One common
quadratic-field element `v` and one rational trace `t_i` per block give
the equivalent system

```math
\overline Bv=hu,\qquad
ht_i=\operatorname{Tr}(va_i),\qquad
(D_i+h)t_i=N(a_i)+N(v).
```

The norm `N(v)` is a quadratic expression and needs no separate register.
The old equations force `B` nonzero; the new common equation does the
same in the reverse direction. No private trace is inverted. This saves
**ten variables and ten equations** for twelve blocks.

## An independently proved binomial block

The [binomial certificate](../undecidability/papers/binomial_pell_certificate.tex)
([PDF](../undecidability/papers/binomial_pell_certificate.pdf)) proves an
exact polynomial characterization of

```math
b\text{ is a positive power of two},\qquad M\mid\binom{2r}{r},
```

for arbitrary integers `r>=1`, `M>=2`, `2<=b<=2M`. The proof independently
identifies two Pell indices, proves a one-sided approximation with an
explicit error bound, and uses integer rounding to establish both
directions. Its boundary example `r=1, M=2, b=4` is covered.

For `M=n^2`, its parameter is `p=2*w*s^2*r^2*n^6`. A division-free
six-coordinate implementation uses `Y=s*n^2`, `L=rY`, `L2=L^2`,
`U=w*n^2`, `p=2*U*L2`, `a=(U+1)*L`. Thus it costs no more coordinates
than the old local block. This independent theorem does **not** silently
replace the `n^2` parameter in the headline `U_em` tables. It also does not
establish the universality of the source's coding prefix.
