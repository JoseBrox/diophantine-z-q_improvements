# Independent review of the rank-one common-level obstruction

Reviewed note: `package/common_level_scope.md`, SHA256
`f777c038f9e2d90dd761e1965b5947bc25cb0a0005bdca4294c31cd6c008ce58`.

**Scope and outcome:** the elementary rank-one obstruction in the second
section is correct. This separate receipt does not certify the note's
quaternion alternative or re-audit the retained simultaneous-twist theorem.

Let \(n>0\) be squarefree with \(n\equiv5\pmod8\), and suppose
\(E_n(\mathbb Q)\) has rank one. The abscissa descent homomorphism
to \(\mathbb Q^\times/\mathbb Q^{\times2}\) has two-torsion image
\(\langle-1,n\rangle\). If \(R\) projects to a generator of the
free quotient and \(\alpha\) is its abscissa square class, the full
image is contained in
\(\langle-1,n,\alpha\rangle\). This conclusion remains true if
\(\alpha\) already belongs to the torsion image; the displayed set
then has fewer elements.

The positive classes in the torsion image are \(1,n\), of two-adic
classes \(1,5\), respectively. Choose the positive sign of the
representative of \(\alpha\). Its positive translates are
\(\alpha,n\alpha\), and their two-adic classes differ by the
nonsquare class 5. At most one can therefore have any one prescribed
two-adic class. For prescribed class 1, the possible extra torsion class
1 is excluded by the globally nonsquare input assumption. For prescribed
class 7, neither positive torsion class qualifies.

Consequently two distinct positive globally nonsquare input classes,
both two-adic class 1 or both two-adic class 7, cannot both occur as
nonzero abscissa square classes on this same rank-one level. The
two-torsion exceptions cause no additional class. The proof does not
exclude a construction sharing a different rational parameter while
using different elliptic levels, and it supplies no new variable bound.
