# Smaller multiquadratic norms and quadratic-tower separation

The four integer-polynomial recipes use the **unchanged v28 arithmetic sources**.
The number of retained coordinates, the sufficient coefficient parameters and
all arithmetic hypotheses are unchanged. The new degree majorants are proved
in `papers/finite_algebra/subalgebra_norms_20261114_v30.tex`.

From the repository root, with SymPy 1.14.0:

```sh
python -B scripts/verify_v30.py
```

`build.py --output DIR` reconstructs four specifications and the degree table.
The producer uses the pinned v28 source generator and square factorizations.
`check.py --directory DIR --output FILE` independently traverses the circuits,
reconstructs every factor and denominator, eliminates binary subspaces with a
different pivot convention, and checks every majorant. It also checks symbolic
identities, nine exact rank-eight examples, and twenty deliberate corruptions.
All 64 point characters in one exact split finite-field fixture for each
conditional source also test every norm factor and affine-support bound.
The release verifier compares generated bytes and performs eight additional
fixed-parameter checks. No production determinant has been expanded.

Each specification provides the native source digest, retained coordinates,
point algebra, square-extracted pole equations, all denominator factors,
subalgebra bases, the quadratic tower, polynomial root envelopes, the single
determinant recipe and exact degree/coefficient/support majorants. A fixed
coefficient parameter has degree zero and is not a quantified variable.
The supplied small fixtures are not newly certified defining members.

`verification.json` records exact checks; it does not certify the infinite
arithmetic inputs, an independent mathematical review, or a smaller variable
count. The unchanged v29, v28, v27 and legacy checks remain separate suites.
