# Finite exceptional square classes

The [theorem](../../../papers/pole_parameters/finite_complement_classes_20261116_v46.tex)
allows finitely many levels `a=17*m^2` and fixed square classes supported on
the source's original exceptional primes in the native complement criterion.
The local valuation implication and every whole-point-algebra guard remain
valid. Finite unions use products of separately encoded polynomials and add
no retained coordinate.

The resulting counts **21 and 9 are conditional targets**. Rational
realization on actual guarded detector tuples remains unproved; the current
general records stay at 25 and 13. The exceptional set cannot be enlarged
to include a prime consumed by the source's soundness proof.

An exact conic family gives infinitely many prepared coefficient inputs
whose complements have square class 409 and are not rational squares.
These inputs demonstrate a strict enlargement of the coefficient locus;
they are not asserted to arise from native elliptic detector tuples.

Run from the repository root:

```sh
python -B computation/pole_parameters/finite_classes_v46/check.py
```

The checker verifies exact root-clearing and parity identities, a finite
branch-collision example, the conic identities, real sign certificates, and
valuation certificates valid on the entire integer progression. With
`--output FILE` it writes a regenerated receipt; otherwise it compares
against the committed certificate without changing files.
