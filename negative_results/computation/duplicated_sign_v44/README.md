# Duplicated elliptic reference signs

The companion theorem is
[`duplicated_reference_signs_20261116_v44.tex`](../../papers/elliptic_charts/duplicated_reference_signs_20261116_v44.tex).
At the split prime76537, the global progression

\[
H_j=[10435875+61021500j]R_0
\]

has `[2]H_j` reducing to the identity in one embedding and
`[2](H_j-P)` reducing to `(0,0)` in the other. These reference
points are in the complete quartic point domain and have half-integral
indices. The resulting formal-parameter translation signs are opposite.

The theorem concerns the reference branches. It does not supply a
complete detector tuple or contradict a defining-polynomial theorem.
Gaussian ray restrictions belong to completeness and are not assumed
for every soundness contact prime.

Run from the repository root:

```sh
python negative_results/computation/duplicated_sign_v44/check.py
```

The checker uses the Python standard library and the separate retained
affine and Jacobian implementations in `mixed_sign_v42`. It reconstructs
all reduction data, exact orders, the progression, a finite-field half
of the order-four residue point, and an exact rational contact. It writes
`verification.json`; `--output PATH` reconstructs a separate certificate.
The proof, verifier, and exact source files are bound by SHA-256.

The finite-field double group is distinguished from the reduction of
the global subgroup generated by `P`. The former contains the relevant
order-four point, whereas the latter has order4786 at that place.
