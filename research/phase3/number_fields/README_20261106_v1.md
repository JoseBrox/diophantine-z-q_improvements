# Number-field checks and norm encodings, 6 November 2026

These are fresh research artifacts. No frozen phase-two file is changed.
All variable counts include the input. These results distinguish literal
base change, encoding a system over a specified field, and defining that
field's ring of integers. The last assertion is **not established** by
the encodings below.

## Main results

1. The literal quartics with 1315, 1339, 1367, and 1391 variables accept
   every input over every characteristic-zero field containing `i`.
   This is an exact generic witness identity, independently checked
   against both the expanded coefficient tables and their residuals.
2. The unshifted indexed polynomials with 41, 43, 43, and 45 variables
   equal **1 identically** when the input satisfies `X^2=2399`, `X^2=-1`,
   or `X^2=-2`. Those algebraic integers are also excluded by the four
   unshifted quadratic residual systems. The separately produced
   shift-2402 constructions are outside this counterexample's scope.
3. Over an explicit totally real quartic base field, the two-coordinate
   halfpoint chart has a point whose double passes every finite elliptic
   anchor exclusion simultaneously.
   This disproves extension of the fixed cyclic-group inference. It
   is not a complete false-positive witness for the entire source.
4. No fixed existential finite formula of equations, guards, and finite
   alternatives can define the integer rings of **all** number-field
   extensions. The proof uses constructibility. A real-closed-field
   argument also supplies a bad extension with a real embedding.
5. A division algebra of degree `ceil(sqrt(r))` combines `r` equations
   of degrees at most `D` into one equation of degree at most
   `D*ceil(sqrt(r))`, with no new variables. For any specified number
   field its norm can have integer rational coefficients, chosen
   effectively using that field.

Each artifact embeds the full residual list and an exact cyclic-matrix
determinant specification. It does not contain an expanded degree-72
or degree-74 coefficient table. The cyclotomic symbol is eliminated by
finite coefficient extraction, and is not an extra quantified variable.
The coefficient of the highest pure input power is 1, so the degree
is exact and each polynomial is primitive.

The degree-36 cyclic norm uses `Q(zeta_37)`, automorphism exponent 2,
and cyclic parameter 2. It is anisotropic over `Q`, over `Q(i)`, and
over every number field of degree coprime to 36. Over an arbitrary
specified field the prime-selection construction gives a different
integer norm with the same degree and variable counts. The fixed
degree-37 norm similarly applies whenever 37 does not divide the field
degree. These are repairs of the equation-combining step: they preserve
the **recorded quadratic systems**, including their arithmetic failures.

For the finite-algebra sources, field-adapted norm conjunction gives
41 variables and degree at most `2^9566686`, or 43 variables and degree
at most `2^250`. These bounds describe their explicit guarded source
systems over a specified field, not definitions of its integer ring.

## Reproduction

Run these commands from the repository root:

```sh
python research/phase3/number_fields/check_quartic_base_change_20261106_v1.py
python research/phase3/number_fields/check_contact_exclusions_20261106_v1.py
python research/phase3/number_fields/check_real_anchor_20261106_v1.py
python research/phase3/number_fields/build_division_norm_specs_20261106_v1.py
python research/phase3/number_fields/verify_division_norm_specs_independent_20261106_v1.py
```

All computations use standard-library exact integer and rational
arithmetic. The independent norm checker imports neither the producer
nor an earlier checker. It verifies source hashes and rows, every
matrix-entry index, Galois conjugacy, inertness, exact degrees,
coefficient bounds, and the four unrounded field-compiler degree bounds.
The receipt files record what was checked. The original arithmetic
theorem and the source's use of Sun's theorem remain subject to their
previously stated review conditions; these algebraic audits do not
certify those separate inputs.
