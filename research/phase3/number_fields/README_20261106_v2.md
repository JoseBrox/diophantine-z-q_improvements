## Exact field behavior

All three literal quartics still accept every input over every
characteristic-zero field containing `i`. The direct checks use:

- Translated1315: anchor coordinates `(55,56,57)=(8S,-2S,-6S)`,
  where `S=3^(2^27)`; Gaussian coordinates 72 and 73.
- 1338: Gaussian coordinates 95 and 96; other witnesses zero.
- 1335: Gaussian coordinates 92 and 93; other witnesses zero.

The translated1315 transformation is an invertible rational affine
change, so literal-polynomial input projections agree over every
characteristic-zero field. The two eliminations preserve the
quadratic conjunctions over every field. For their literal sums of
squares, the reverse implication is proved over fields with a real
embedding; arbitrary nonreal cancellation solutions need not survive
elimination. The Gaussian sections were checked directly in each new
expanded table and by independently squaring its restricted residuals.

The unshifted contact contradictions are preserved by the system
isomorphisms and by faithful norm encoding. The separately emitted
shift-2402 artifacts remain outside that counterexample's scope.

Include `final_quartic_fields_20261106_v2.tex` after the v1 division-norm
chapter. It introduces no new bibliography keys. The construction

Run from the repository root:

```sh
python research/phase3/number_fields/check_quartic_base_change_20261106_v2.py
python research/phase3/number_fields/build_division_norm_specs_20261106_v2.py \
  --translated research/phase3/quartic/quartic-direct-translated/polynomial.json.gz \
  --eliminated research/phase3/quartic/quartic-direct-small-coefficients-1338/polynomial.json.gz \
  --folded research/phase3/quartic/quartic-direct-small-coefficients-1335/polynomial.json.gz
```

The producer refuses to overwrite an existing norm specification with
different bytes. All source and output hashes are in the construction
report. The independent norm checker imports no producer and rechecks
the matrix, source rows, fixed constant interpretation, and coefficient
bounds. The final quartic transformation audit is separate:
`research/phase3/quartic/verify_final_transforms_independent.py`.
