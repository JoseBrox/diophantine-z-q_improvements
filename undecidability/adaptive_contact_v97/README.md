# Adaptive contact spacing: blocked research checkpoint

These are complete **algebraic candidate tables**, not accepted
undecidability witnesses. They are deliberately excluded from the result
registry. The smaller counts in their certificates describe the candidate
coefficient tables only.

The proposed spacing is `D = r_imag / 2^24`, using an existing common
scalar-chart coordinate. Local valuation calculations show that this would
separate the contact lists for a fixed reference. An independent audit found
that `r_imag` changes when the reference index is later adjusted to satisfy
the selected-prime congruences. Thus the contact coefficients are not
established fixed data for the retained prime supplier. No moving-family
supplier theorem or reference-invariance identity has been proved.

The complete reasoning, source references, local formulas, obstruction, and
next possible route through actual difference-point invariants are in
`undecidability/joint_research_v94/continuation.md`.
