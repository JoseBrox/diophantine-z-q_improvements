# Exact elimination across all three quartic routes

This directory records reversible eliminations over the rationals in the frozen complete source tables, preserving their hypotheses and their whole solution projections (with eliminated coordinates recovered). The following counts result:

| Route | Old variables / rows | New variables / rows |
|---|---:|---:|
| general | 884 / 749 | 884 / 749 |
| specified | 1049 / 912 | 1049 / 912 |
| abc | 324 / 273 | 323 / 272 |

Each step either replaces a row by a linear combination of rows whose coefficient on the replaced row is a nonzero integer, or solves a row a*x=P for a nonzero constant integer a and P independent of x. The latter step substitutes P/a into all other rows, clears only powers of the nonzero integer a, and removes the defining equation. Reconstruction in reverse order gives precisely the original zeros. Dividing any row by its nonzero integer coefficient content is reversible. The solver only substitutes a quadratic P when x occurs linearly in all other rows; otherwise it uses affine P. In both cases degrees remain at most two in quantified coordinates. Parameters remain fixed polynomial coefficients. There is no division by a parameter or a quantified variable, and no added exclusion. The compiler records every solved formula and row combination and checks degree and support. The exact elimination does not audit or change the inherited arithmetic or external coding hypotheses.

Reproduce from this directory with node build.mjs (or --write to regenerate). Each original Git blob is pinned in the script. The current tables were generated by running the exact same reduction on the fetched pinned inputs. No full historical CI run is asserted.
