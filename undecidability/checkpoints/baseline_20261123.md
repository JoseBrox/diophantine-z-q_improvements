## Reported construction

The Mishchenko--Treier source has 62 positive integer variables and 50
quadratic equations, numbered (8)--(57). Four affine register definitions and
then the affine simplification `c=1+xB+g` were eliminated, with the instance
input `x` treated as a fixed integer coefficient. This gave 57 variables and
45 equations. The previously quoted 57/47 count was not the count used in
the final 2,539-variable transfer.

Fifteen independent source variables were certified integral. Polynomial
reconstruction and the fact that a rational number whose square is an integer
is itself an integer were used for the remaining source variables. Sixteen
primitive positivity conditions and two derived strict-positivity conditions
were imposed. The other derived signs were argued to be automatic.

For an integer `n`, strict positivity is equivalent to

```math
n=1+\sum_{j=1}^3 \frac{t_j(t_j+1)}2,\qquad t_j\in\mathbb Q.
```

Necessity follows from the three-triangular-numbers theorem. For sufficiency,
each summand is at least `-1/8`, so the right-hand side is positive. Two
single-use positivity slacks can be replaced by these expressions. The
reported count is therefore

```math
(57-2)+3(16+2)+15(m-1)=15m+94.
```

For the 137-row integer predicate in 163 total coordinates, the reported
result is a sum of 2,116 quadratic squares in 2,539 rational coordinates.
Instantiating the same transfer with the 151-row, 179-coordinate source gives
2,779 coordinates; the 46-row, 56-coordinate ordinary-abc source gives 934.

## Correction already incorporated

The source Pell row contains `Gamma_19^2`, not `Gamma_19`. Treating it as
linear incorrectly removes a coordinate. The final reported 2,539 count
retained this square. Its root is integral by rational-root integrality and
its sign can be selected positive because its other occurrences are squared.
