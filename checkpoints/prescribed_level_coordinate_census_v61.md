# Coordinate census for the prescribed-level route

The positive varying-level theorem retains two rational pole parameters r,s per block and one finite quadratic ordinate. The ordinate is already part of the shared finite-algebra encoder.

If a future theorem supplies r as a fixed rational function of existing source coordinates and proves rational solubility of its fiber on every required actual tuple, s is still free. This would save at most one retained coordinate per pole block before any new helpers or guards are counted.

Accordingly, such a theorem alone would potentially change25 to23 for two general blocks,13 to11 for two conditional blocks, or11 to10 for the one-block ordinary-abc source. These are census implications only: none of these new constructions has been proved in this checkpoint.

The targets21 and9 require eliminating both rational parameters in each of the corresponding two blocks, or a different complete saving elsewhere. For the one-block ordinary-abc source, both pole parameters must be eliminated to pass from11 to9.

The actual-level problem is:
d=28u/((1+u)^2 V^2), V=Tr(W^-1),
k=(1-d)(d+r^2)/(d-r^2).
For r already supplied by the source, the fiber y^2=d(k^2-s^4) has a rational point exactly when E_(dk)(Q) represents abscissa class[-d]. This still leaves the abscissa magnitude s to be chosen.

A compatible fixed twist n with d*k/n a rational square is sufficient for that class condition, using the point class on E_n from the fixed-d theorem and its rational two-torsion translate. No theorem realizes this condition on every actual detector tuple.

Changing the existing slope to choose r also changes u,W,V and d. The theorem selecting levels after d is fixed cannot be applied as though d were unchanged. Likewise local analytic lifts, density and positive rank do not replace the exact incidence required to remove the remaining s coordinate.

The complete actual native-square or square-complement theorem would still give the original21/9 reduction, with its proved finite-algebra guards and no new retained coordinates. That realization remains unproved.
