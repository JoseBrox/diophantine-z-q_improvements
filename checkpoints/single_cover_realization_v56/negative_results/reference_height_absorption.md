# Reference-trace denominator obstruction to absorbing auxiliary classes

This obstruction concerns height amplification which also bounds the
reference trace `T_H=Tr x(H)`. It does not rule out rational witnesses
with unrestricted reference height.

At every successful conditional contact outside the fixed exceptional
set, the first and third reciprocal tests put `H` in the formal group
in one slot and `H-P` in the formal group in the conjugate slot. In the
second slot, `H` therefore reduces to `P`. The fixed point `P` has unit
nonzero abscissa outside the existing exceptional set (the only
additional numerator prime is41). Hence the two valuations of `x(H)`
are a negative even integer and zero. The negative one is even because
the source chart has square abscissa.

Their sum `T_H` has that same negative even valuation. Consequently,
if `M_good(t)` is the squarefree product of successful odd contact
primes,

`M_good(t)^2 | den(T_H)`.

For a criterion twisted by a rational squareclass `delta`, only primes
of odd valuation in `delta` may be omitted from the extraction. Thus

`log M(t) <= (1/2) h(T_H) + log rad_S(delta) + O(1)`.

Suppose a proposed amplified height `E` dominates `h(T_H)` and obeys
`log rad_S(delta) <= k E + O(1)`. The contact estimate and an amplified
argument giving `E <= q log M(t) + O(1)` imply

`E <= q(k+1/2) E + O(1)`.

If `q(k+1/2)<1`, then `E` is bounded for every solution, including
integer inputs. If the amplitude also contains `X^2+B`, all sufficiently
large fixed shifts eliminate every solution. This is the same strict
coefficient inequality one would otherwise use to absorb the class
support and the bound `h(X)<=E/2` in an integrality contradiction.

Therefore simply adding the reference height to the amplifying
argument, in order to absorb the limiting norm class or an arbitrary
class depending on all auxiliary points, cannot establish completeness
by that height budget. A successful alternative must leave the needed
auxiliary height unrestricted or use a different support estimate.
